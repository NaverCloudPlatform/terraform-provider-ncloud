# Resource: ncloud_subaccount

Provides a Sub Account resource.

~> **Note:** This resource requires main account API keys. Sub account credentials cannot manage sub accounts.

~> **Note:** All arguments including `generated_password` will be stored in the raw state as plain-text.
[Read more about sensitive data in state](https://developer.hashicorp.com/terraform/language/state/sensitive-data).

## Example Usage

```hcl
resource "ncloud_subaccount" "ci" {
  login_id               = "ci-deployer"
  name                   = "CI Deployer"
  can_api_gateway_access = true

  api_allow_sources = [
    {
      type   = "IP"
      source = "10.0.0.0/24"
    }
  ]
}
```

## Argument Reference

The following arguments are supported:

* `login_id` - (Required) Login ID of the sub account. Changing this creates a new sub account.
* `name` - (Required) Name of the sub account.
* `email` - (Optional) Email address of the sub account.
* `memo` - (Optional) Memo for the sub account.
* `can_console_access` - (Optional) Whether the sub account can access the console. Default: `false`.
  When enabled at creation, an initial password is generated by the API and exposed once via `generated_password`;
  the user must reset it at first login. Enabling console access on an existing sub account does not generate
  a password — reset it from the console instead.
* `can_api_gateway_access` - (Optional) Whether the sub account can access APIs through API Gateway.
  Required to issue access keys. Default: `true`.
* `is_mfa_mandatory` - (Optional) Whether two-factor authentication is mandatory for console login.
* `console_permit_ips` - (Optional) List of IP addresses allowed to access the console. Omit to allow all.
* `api_allow_sources` - (Optional) Sources allowed to call APIs with this sub account's access keys. Omit to allow all.
  * `type` - (Required) Type of the source. Valid values: `IP`, `VPC`, `VPC_SERVER`.
  * `source` - (Required) An IP address (CIDR allowed) for `IP`, or an instance number for `VPC` / `VPC_SERVER`.

## Attributes Reference

* `id` - The ID of the sub account.
* `sub_account_no` - Number of the sub account.
* `nrn` - NCP Resource Name of the sub account.
* `active` - Whether the sub account is active.
* `create_time` - Creation time of the sub account.
* `generated_password` - Initial console password, generated only when `can_console_access` is enabled at creation.

## Import

### `terraform import` command

* Sub Account can be imported using the `id`. For example:

```console
$ terraform import ncloud_subaccount.rsc_name 2fbf74af-...-a30c
```

### `import` block

* In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import) to import Sub Account using the `id`. For example:

```terraform
import {
  to = ncloud_subaccount.rsc_name
  id = "2fbf74af-...-a30c"
}
```
